# PS3 game updates

## Rusty PSN

Rusty PSN is the local utility used to find and download official PS3 game
update packages. It is a downloader, not a package installer.

- Executable: `/home/service/Desktop/ps3/ripping/rusty-psn-egui-linux/rusty-psn`
- Download directory: `/home/service/Desktop/ps3/ripping/rusty-psn-egui-linux/pkgs/`

Install a downloaded `.pkg` into the intended RPCS3 instance only after its
game session has been closed. For WebStation, install it into WebStation's
RPCS3 data directory—not the native host RPCS3 installation.
